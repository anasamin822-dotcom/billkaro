# 03 - Copy and content rules

Voice: a small Indian SaaS team talking to freelancers. Short sentences. No jargon.

Rules I held while writing:
- No lorem ipsum or placeholder text anywhere
- No AI-tell phrases ("seamless", "elevate", "delve", "in today's fast-paced world")
- Rupee amounts in INR, Indian names and cities in testimonials
- Fake but believable contact details (hello@billkaro.in, Bengaluru)
- Form errors written like a person ("That email doesn't look right"), not a compiler

Final pass: run the unslop banned-phrase scan over all visible copy, README and
code comments before pushing.
